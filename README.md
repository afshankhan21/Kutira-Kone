KUTIRA-KONE

Kutira-Kone is an Android application that helps users buy, sell, and exchange leftover fabric materials. The main aim of this project is to reduce fabric waste and support small tailors and artisans by making better use of excess materials.

Problem Statement

Many home-based tailors and boutique owners have leftover fabric pieces that are usually discarded. At the same time, other users require small pieces of fabric for activities like patchwork, doll making, and small craft projects. There is no proper platform to connect these users and enable material exchange.

Project Idea

Kutira-Kone acts as a local marketplace where users can upload their extra fabric and others can browse and use it. This helps reduce waste and promotes a simple circular economy within the community.

Features

• Upload fabric scraps with image and details  
• Browse available fabrics  
• Image upload and storage using cloud services  
• Real-time data updates  
• Filter fabrics based on material (Silk, Cotton, etc.)  
• Nearby fabric discovery  
• Option to exchange fabrics  
• Basic design ideas for using small fabric pieces  

User Flow

1. User uploads fabric with image and details  
2. Other users browse or search for fabrics  
3. Users find nearby listings  
4. Users request to buy or exchange  

Tech Stack

• Kotlin  
• XML (Android UI)  
• Firebase Firestore  
• Firebase Storage  

Implementation

• Grid layout used for displaying fabric items  
• Firebase Firestore used for storing and syncing data  
• Firebase Storage used for handling images  
• Filtering implemented based on fabric type  
• Basic concept of location-based search  

Impact

• Helps reduce textile waste  
• Provides affordable materials for small users  
• Encourages local community interaction
